# Stone Paper Scissors

A simple, interactive Stone Paper Scissors (Rock Paper Scissors) game built using HTML, CSS, and JavaScript. Play against the computer and see who wins each round!

## Features
- Play against the computer
- Randomized computer choice logic
- Clean and responsive UI

## Tech Stack
- HTML — structure
- CSS — styling
- JavaScript — game logic

## How to Play
1. Clone the repository
2. Open `index.html` in your browser
3. Choose Stone, Paper, or Scissors and see who wins!
